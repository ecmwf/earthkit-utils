Concepts
========

**earthkit-utils** is a collection of small, focused utility functions that are
shared across the EarthKit ecosystem. Each subpackage addresses a specific
cross-cutting concern — such as unit conversion, array namespace detection, or
decorator helpers — so that the rest of the EarthKit libraries can depend on a
single, well-tested implementation rather than duplicating the logic themselves.
