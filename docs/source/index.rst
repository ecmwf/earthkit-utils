Earthkit-utils documentation
============================

.. important::

   This library is in **beta** and may still evolve as the EarthKit ecosystem grows.

**earthkit-utils** provides shared helpers for the EarthKit ecosystem, including array namespace detection,
unit conversion, and decorator utilities.
